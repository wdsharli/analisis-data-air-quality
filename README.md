# Proyek Analisis Data: Analisis Kualitas Udara (Air Quality Dataset)

Proyek ini bertujuan untuk menganalisis data kualitas udara dari stasiun pemantauan (seperti Stasiun Aotizhongxin) serta membangun dashboard interaktif berbasis web menggunakan **Streamlit** untuk menampilkan hasil eksplorasi data.

---

## 📁 Struktur Direktori
```text
submission/
├── dashboard/
│   ├── dashboard.py
│   └── main_data.csv
├── notebook.ipynb
├── requirements.txt
└── README.md
git clone https://github.com/wdsharli/analisis-data-air-quality.git
pip install -r requirements.txt
streamlit run dashboard/dashboard.py
